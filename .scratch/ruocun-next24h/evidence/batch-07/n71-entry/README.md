# 71 启动和动态发现对照

冻结 `src/index.ts` 的 293–327 行定义评测及单通道开关。744–795 行分别控制磁盘、用户代理与内置目录。1157–1190 行的来源动态发现与安装后加载没有同样的禁用保护。本项目在启动和回调两处共用磁盘技能开关。

实际普通入口依次执行普通模式、`--eval`、`--eval --no-skills --no-hooks`。每次通过固定合成模型执行 TodoWrite 和嵌套文件 Read。普通模式在下一轮加载嵌套技能，评测模式关闭启动磁盘读取与读取文件后的技能激活。合成项目指令、磁盘代理、MCP 配置路径和联网工具均有对照。评测模式保留内置 Skills、SessionStart Hook、记忆工具和来源规定的启动 GC。显式关闭 Skills 或 Hooks 时，对应通道关闭。Hook 执行及初始 MCP 连接使用可观察的测试端口，真实回环 MCP 恢复另见相邻 `n71-recovery`。
