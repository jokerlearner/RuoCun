# 47 会话内循环候选

对照冻结 `src/tui/app/App.tsx:285–287,528–552` 和 `src/agent/session_scheduler.ts`。普通 `/loop` 沿来源解析整数 `s/m/h`、空参停止及 `off`，从首个完整间隔后通过现有输入账本接纳。队列去重在同一把锁内。重设、off和关闭等待正在提交的接纳，关闭不会留下计时器。关闭前已确认的输入继续由现有会话队列处置。遇到会话错误或未确认保存，计时器停止自动提交。保留来源 `setInterval` 对零值和超界的最短周期归一。

合成调度测试在缺入口时失败，修复后受影响回归12项通过。普通InputBroker输入 `/loop 1s`，回环请求替身收到一次规范化提示，`/loop off` 后无后续请求。Ruff和mypy通过，原始白名单回执见 `raw/`。真实终端技术合验归批末。
