# 67 任务面板与后台交接

冻结 `src/tui/app/App.test.tsx` 的 Ctrl+T/G/B 行为以同一 Python 输入 owner 验证。任务面板查看实际子代理与 fork，选中项显示中间调用/结果、工具次数、状态和可翻页历史。手工任务和 Shell 不混入该面板。历史选择从最近用户消息起，回看临时渲染，不向主转录追加历史。面板输入不改主草稿，Esc 优先关闭面板，审批出现时优先取得输入。Ctrl+B 仅在忙碌且无模态时请求普通入口转换，成功数大于零时显示来源反馈。

`n67-panels-red` 保存未接入面板的源行为复现，`n67-panels-green` 通过 Ctrl+T 活跃输出/失败项、Ctrl+G 定位、Esc 保留 Unicode 草稿和 Ctrl+B 提示的原有语义。定向 Ruff、Mypy 通过。合成输入不代表实际 Windows Terminal 视觉与缩放验收。

## 前台 Agent 交接

冻结 `src/tui/foreground_registry.ts`、`src/tools/agent.ts` 和 `src/agent/runAgent.ts` 使用前台登记、原执行器收口、新任务 ID 与独立中断信号。现有 `TaskManager.convert_foreground()` 登记仍运行的普通、fork 和 `isolation:"remote"` 代理。等待最多五秒获取已保存工具对的模型边界，未获得边界的请求过期。确认边界后旧代理不再发起模型或工具调用。新后台代理接续原会话、用量、模型、权限、剩余轮次和对应工具目录。显式 `worktree` 隔离继续走前台路径，结果未确认的操作保留原现场。UI 的成功数来自已确认的交接。

现有 SQLite `RunRecord` 事务校验同一父工具、原前台执行身份、完整消息对、无未决工具、有效预算及工作区材料。在同一事务保存原前台记录终态和新的后台 run；记录双向 run 引用。后台再次检查此收据。前台任务面板读取实际已保存的消息。终态和收据已确认前不报告转换成功。

`n67-agent-red` 缺少原前台真实任务登记。`n67-agent-final` 在白名单合成环境中通过新路径和直接受影响的38/40，共10项。用例实际写两个合成文件，Ctrl+B 等待第一次工具结果提交，旧结果在新模型请求出现一次，旧父信号随后设取消，新后台仍完成第二次写入；确认不同 run、已提交双向交接关系和剩余预算。`n67-agent-static-final` 和 `n67-agent-ruff-final` 通过。普通入口和真实终端结果由主协调另行核验。

冻结 `agent.ts` 的 `!isolate` 分支接受 fork 与 `remote`。fork 使用同一父请求精确工具快照与派发定义，持久记录摘要用于本次交接认证；原特殊 fork 的重启限制继续生效。`remote` 交接前以原 Worktree 对象核实目录、管理目录、分支与登记身份，新执行在相同目录运行。按已确认的隔离收尾策略，完成后检查工作树，保留改动与独有提交，干净且身份可信时清理。失败或取消保留目录，清理结果不明记 unknown。冻结转后台调用保留原路径，其生命周期本身没有调用前台的清理函数。

`n67-special-red` 的远程夹具最初缺少白名单 Git 路径，按既有工作树夹具修正。`n67-special-red-boundary` 在 fork、remote 两项复现旧交接拒绝。`n67-special-green` 通过普通、fork 与41精确工具用例，远程项首次因漏导入失败；`n67-remote-final` 修复后通过真实临时 Git 工作树，交接前后写入同一分支且保留改动。fork 用例复用同一线上的工具目录，并真实调用一个普通后台白名单外的精确工具。定向 Ruff、Mypy 均通过。
