# 若存 Code

若存是用 Python 编写的终端编码助手，支持工具调用和会话恢复。当前技术交付为 Windows x64、CPython 3.11 的标准 Python 包 `0.1.0.dev0`，使用 `ruocun` 或 `python -m ruocun` 进入终端界面。
