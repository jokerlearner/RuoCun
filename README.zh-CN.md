# 若存 Code

若存是用 Python 编写的终端编码助手，支持工具调用和会话恢复。当前发布版 `0.9.0` 面向 Windows x64 和 CPython 3.11，使用 `ruocun` 或 `python -m ruocun` 进入终端界面。
