# 保存项目运行方法

从 README、包脚本、Makefile 或项目配置找团队实际采用的入口。核对构建、启动与测试各自的工作目录、环境、端口和成功信号。有疑问时用 Bash 在合适的环境运行代表性命令，或确认所需条件。

在 .ruocun/skills/run-<项目名>/SKILL.md 写下已核实的流程。frontmatter 包含匹配目录的 name 和不超过 60 字的 description，描述说明何时调用，命令放在正文。需要按路径匹配时可填写 paths。按任务列出命令、前置条件和结果判据，涉及读取、执行或编辑时使用若存的 Read、Bash、Edit 名称。

交付时列出技能路径、收录的入口及未能实跑的命令。
