# ADR-0012：继续项目指令、基础Skills与上下文管理

Status: Accepted
日期：2026-11-10

用户明确继续后续开发、暂不体验，保持原对齐规则，并选择A：项目指令/基础Skills＋上下文管理。此决定授权本批实施，覆盖ADR-0011只在首版暂时后置的对应能力；首版人工状态继续pending，旧82票不因拆片自动resolved。

本批复用现有Read/工具回合、Session/cost、StorageWorker与标准包。补齐需要的08/28接缝，沿34的静态Skills与29的上下文管理实现。工程AGENTS与产品指令分离：按ADR-0005/D09读取原生RUOCUN.md/local及显式只读兼容源，恢复Git根到cwd的顺序；不自动读取工程AGENTS/CLAUDE作为产品指令。

基础Skills保留冻结元信息、发现/覆盖/slug/namespace、模型及用户调用和8个core资源原文；动态激活/安装、插件、MCP、子代理与完整TUI不在本批。用量与预算沿R1：历史累计token可恢复，分模型费用仅本进程，默认提醒、显式hard开关才停止；上下文估算/85%触发及手动压缩沿来源，粗估不冒充精确token。

压缩失败的已确认差异：用户Q2选择“保留原上下文并停止本轮”，替代DAO compactMessages摘要异常后硬截断继续的分支。失败时原模型上下文保持，提示失败后停止该轮；成功摘要仍沿来源生成候选，持久化确认后才替换。已确认输入账本与工具记录不因压缩丢失或自动重放。来源硬截断用例保留为差异，不冒充迁移通过。

工作流沿ADR-0009/0010：来源断言TDD、普通小批、关键共享/存储接缝先独审、主协调＋2实现＋独立审查四槽。五项既有工程入口及最小Python/Windows交付确认保持；真实模型API0调用、人工体验后置。来源参考技能及许可保持原样。本批规格/文件归属见[阶段A](../../.scratch/ruocun-advanced-a/spec.md)。
