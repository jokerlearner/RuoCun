# ADR-0018 — 若存原生配置与产品文案

Status: Accepted

日期：2026-11-12

## 决定

- 账户从若存用户目录的原生配置或显式 `--config` 文件加载。系统凭据只从若存的服务和账户命名空间读取。
- 启动使用若存的设置和扩展入口。账户及扩展不再通过跨产品来源映射装配，产品环境开关统一使用 `RUOCUN_` 前缀。
- 新会话记录使用若存标识。恢复已有若存会话时，仍识别其已经持久化的启动事件标记，防止重复注入。
- 终端、帮助、模型提示词和产品说明使用若存名称。版权与第三方来源记录集中在许可与归属文件中。

## 迁移

本机当前使用的硅基流动账户已迁至若存原生配置。系统凭据写入和本机读回已核对，模型与服务地址沿用，迁移没有发出模型请求。原账户文件和同文件中的其余账户保留在原应用，旧来源映射另存以便回退。
