# ADR-0017 — 子代理工作树创建失败时拒绝派发

Status: Accepted
日期：2026-11-11

用户确认“隔离创建失败就拒绝派发”。工具参数或角色定义要求 `worktree` 或 `remote` 时，先核实同机 Git 工作树创建完成，再运行子代理。可确认的创建失败以工具错误返回，模型可修正条件后重新提交。Git 写入结果未确认时保留现场，按现有恢复规则停止受影响操作。

冻结 `src/tools/agent.ts:198–225` 在明确没有创建工作树时可能继续在原目录运行。本决定保留用户对执行目录的约束。`remote` 对照冻结行为使用同机 Git 工作树，并明确提示实际运行位置。`fork` 与显式隔离参数互斥，避免组合参数中的隔离要求被忽略。
