# ADR-0002：独立仓库与纳入 Git 的本地工程记录

Status: Accepted
日期：2026-11-05
决定来源：用户明确的工作流选择及对配置草稿的确认。

## 背景

后续会话及独立 worktree 需要直接读取项目目标、规格、任务与架构决定。
参考项目用于读取和对照，RuoCun 的产物写入独立目标项目。

## 决定

- RuoCun 使用独立 Git 仓库，初始分支为 main。
- Issue tracker 使用 .scratch/<feature>/ 下的本地 Markdown。
- 每张任务票独立成文件。
- 使用根目录单一 CONTEXT.md 和 docs/adr/。
- 开发代理规则使用根目录 AGENTS.md。
- 规格、任务票、ADR、模块对应表和验收矩阵全部提交入库。
- 创建后续 worktree 前，先提交其需要读取的工程记录。
- Codex 负责实施和自动验证，用户负责决策与体验验收。
- 实现状态、自动测试结果和用户体验验收分别记录。
- 保留来源代码必要的版权、许可及归属声明。

## 取舍与后果

本地 Markdown 将工程记录与代码共同版本化，适用于当前项目。
单一上下文提供统一目标入口，具体决定和执行记录通过相对链接按需读取。
.scratch/ 虽采用技能默认目录名称，但在本项目中属于正式记录。
本次初始化建立本地仓库和首个文档提交；远程发布不属于本次交付。
