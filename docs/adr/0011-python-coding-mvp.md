# ADR-0011：启动纯Python实用编码首版

Status: Accepted
日期：2026-11-10

用户选择保持纯Python、首版只做实用编码闭环，确认Q1逐轮文字交互和Q2暂不自动压缩，随后明确“现在开始执行这个首版吧”。本决定替代当前停止边界，并在首版交付中覆盖ADR-0010及旧完整任务图的超出部分；原82票保留后续迁移记录，不虚标完成。

首版交付七个实际工具Read、Write、Edit、Glob、Grep、Bash、TodoWrite；普通文字多轮输入和流式输出；写入/编辑/Shell明确审批；前台请求及受管进程树取消；复用07正常会话保存重开；标准Python包仓库外安装。模型达到上下文上限时明确停止、保存记录，由用户新开会话继续，不静默删历史。复用现有配置、Chat/Responses、重试和Session/cost基础。

后置：忙时输入队列、持久后台runner/接管、子代理/fork/长期任务、记忆反思、自动压缩、完整TUI/Sixel/面板/图片剪贴板、动态Skills/Hook/插件/MCP/LSP/Deck、评估配套、自动CI及完整手册。基础文本编码和必要项目说明保留，首版只注册已实现工具；不支持的参数/命令准确拒绝。

采用显式文字审批，不宣称已实现旧全规格的分层权限/auto分类/Hook审批。文件工具保持来源的读取基线、并发修改检查与所选路径约束；Bash只前台，background=true明确拒绝，不能伪装后台。既有SQLite私密数据、owner/事务及源码来源保持；工具意图在副作用前记录，未知副作用不自动重做。首版没有完整恢复决定UI，遇未决项明确停止并提供诊断，不能为了继续而丢弃它。

独立任务与交付标准见[首版规格](../../.scratch/ruocun-mvp/spec.md)。使用主协调＋两个实现＋独立审查四槽，在既有集成分支实施；共享接口先固定，普通实现按批送审，关键运行接缝集成前复核。沿DAO已有输入/预期迁移，仅增加语言/Windows适配必需的最小确认。没有真实模型费用授权时使用合成端点，不调用付费API；人工终端体验单列。

24–48小时为首版冲刺目标，首4–6小时以可运行读改文件闭环校准；不是到时自动通过。后续高级功能不是首版阻塞项，旧issue_graph不用于首版派发，首版按本地M01–M04任务追踪。
