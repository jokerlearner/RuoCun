# ADR-0001：Python 迁移边界与 Windows 优先验收

Status: Accepted
部分范围已由[ADR-0010](0010-selected-scope-and-lean-workflow.md)修订；本文件保留初始决定。
日期：2026-11-05
决定来源：用户明确目标及对工作流草稿的确认。

## 背景

本项目将 DAO 的 TypeScript 实现迁移为 Python，需要保持可追溯的功能与行为对应。
用户要求尽量保留目录、模块职责和主要调用关系，并在 Windows 上优先验收全部功能。

## 决定

- 核心实现全部使用 Python；语言绑定的底层依赖允许替换。
- 尽量保留原模块职责和主要调用关系，外部可观察行为逐项对照。
- 配置、Skills、Hooks、MCP 等扩展格式保持兼容。
- 外部扩展按其声明的命令和协议运行。
- 不要求迁移旧 DAO 会话；完整实现 RuoCun 自身的会话保存和恢复。
- 补齐 Windows 平台缺口；Linux/macOS 保留跨平台设计，后续实机验收。
- 项目名称使用 RuoCun；Python 包名和命令名使用 ruocun。

## 取舍与后果

保持模块对应关系便于核查迁移遗漏，语言绑定依赖无需机械照搬。
具体依赖通过后续选型任务确定，替换依据和行为差异记入模块对应表及相关 ADR。
Windows 使用平台实现补齐能力，验收矩阵分别记录各平台证据。
跨平台设计或交叉构建产物不代表已完成其他平台的实机验收。
行为偏离既定目标时，由用户作出取舍决定。
