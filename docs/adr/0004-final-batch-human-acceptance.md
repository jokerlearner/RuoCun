# ADR-0004：人工体验集中到最终整体验收

Status: Accepted
日期：2026-11-05
决定来源：用户明确要求“继续，先不要频繁的让我人工验证，如果有问题最终项目完成后统一改”。

## 决定

- 编码、TDD、来源对照、真实协议/进程/Windows可自动执行的检查继续由Codex完成。
- 人工体验集中到最终整体验收，不逐票请求键盘/窗口操作反馈；已有反馈准确保留。
- D06技术收口依据可运行原型、自动证据、已取得反馈及风险/未验清单；剩余人工项交实现77/78/85统一验收，不阻塞D10等技术路线和继续编码。
- 实现18同样先完成产品路径和自动验证，人工体验归77；技术前置尚未验证、真正外部条件缺失仍按真实依赖记录。
- 原型/自动测试/产品测试/真实模型/最终用户体验分别记状态。后置验收不等于已通过，不减少Windows完整功能、取消恢复或扩展兼容范围。
- 最终77/78/85仍须相应证据和用户实际验收才能关闭；新范围取舍、实质行为变化或必要外部条件集中说明。

## 已有体验证据

用户对D06第一组“中文IME及emoji编辑、流式中两条排队与第三条草稿、连续缩放与历史选择”回复“正常”。只覆盖这些明确子项，不推定粘贴、前后台、焦点图形、退出恢复等其它场景通过。
