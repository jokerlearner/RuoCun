# ADR-0016 — 删除当前账户沿用DAO的进程内连接行为

Status: Accepted
日期：2026-11-11

用户明确选择“沿用DAO，之后手动切换或重启”。删除当前账户时，配置按冻结DAO的removeProfile选择剩余账户或default，当前进程保留删除前已解析的连接、模型和凭据。删除确认后提示用户手动切换账户或重启。没有自动切换、暂停模型并进入配置的新增行为。

代价是配置中的activeProfile及相应状态展示可能与本进程实际连接暂时不一致。下一次显式切换成功后使用新连接；重启重新解析配置，没有可用账户时需重新配置（69首次引导尚待实施）。不能将配置已选中下一个账户表述为当前连接已切换。

本决定只确定删除后的连接语义。凭据和配置保存仍等待确认，结果未明仍保留现场并停止受影响操作；兼容DAO凭据服务保持只读。来源为冻结src/index.ts:565–570及src/config/profiles_store.ts的removeProfile；后端动作与终端选择器共用同一实现。
