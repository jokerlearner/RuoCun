# 若存 0.9.0

以桌面已验证的 89 次候选中文注释版为产品底稿。构包时将产品版本统一为 `0.9.0`，CLI 与包元数据共用 `src/ruocun/version.py`。

## 主要变化

- Windows 可选 MXC 后端、逐次额外写目录授权和受管 Bash 后台接管。启用方式见[Windows 沙箱](../windows-sandbox.md)。
- 工作目录作为尾部运行上下文发送。上下文压缩及恢复行为继续沿用已发布桌面实现。
- 主代理按风险和证据缺口派发独立验收。使用同一环境并服务同一判断的短检查可以合并，失败状态逐项可见。工作状态变化后复跑受影响的检查。
- 增加中文源代码注释，帮助阅读会话、提示词、工具和平台接缝。

## 安装与更新

下载适配 Windows x64 和 CPython 3.11 的 `ruocun-0.9.0-py311-none-win_amd64.whl`。发布同时提供源码包和 `SHA256SUMS`。操作前结束旧版窗口中的活动任务，保留旧环境和会话备份。[下载](https://github.com/jokerlearner/RuoCun/releases/tag/v0.9.0) · [安装与恢复](../install-and-recovery.md)

## 发布验证

从源码包构建 wheel，在仓外独立环境安装，验证 `pip check`、包元数据、`--help` 和 `--version`。92 项定向回归通过。Windows MXC 使用合成会话验证项目内写入、区外写入拒绝、后台输出及进程树取消。此次验证使用本地模型回复。
